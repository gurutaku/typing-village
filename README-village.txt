Village Typing Defenders — Download bundle

Files:
- village-typing-defenders.html: open this in a modern browser to play.
- kid-words.js: external vocabulary bank used by the game.
- kid-words.json: readable copy of the word bank for inspection/editing.

IMPORTANT: Keep village-typing-defenders.html and kid-words.js in the same folder.
The HTML loads the vocabulary using ./kid-words.js.
